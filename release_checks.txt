#                  改的是随包带出去的 shell/字体这类**资源文件**时用这两条（v1.4.58 补）
#   stale-feature <理由>
#                  本轮包内拿不出新名字时的**书面申报**：改动全在打包资产或链上工具，
#                  包内只动了版本号/阶段标签这类字符串字面量（co_names 看不见）。
#                  必须带理由，运行时大声打 WARNING；它只跳过"新增特征"这一条判据。
#                  为什么开这条而不是让人用 --allow-stale-feature：申报要留在受版本控制的
