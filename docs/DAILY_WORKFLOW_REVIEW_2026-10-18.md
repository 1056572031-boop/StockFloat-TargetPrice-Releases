## 已确认问题与修复

| 问题 | 原风险 | 本轮处理与对应证据 |
| --- | --- | --- |
| 导航直接生成裸 unittest 命令 | 没有运行器的单用例超时、弹窗拦截和数据检查 | 改用既有 `test_runner.py --module`；定向模式的失败、弹窗和数据红线测试 |
| 单独使用运行器未设置全量脚本的数据路径 | 产品导入可能先绑定真实配置/日志路径 | 定向模式在导入前创建独立临时路径；正常/异常退出恢复与清理测试 |
| 普通/嵌套 `test_*` 函数被当成可运行入口 | 静态通过但 unittest 可能零用例成功 | 检查顶层测试类形状；运行器零用例直接失败；函数/异步反例与空套件测试 |
| 空导航、空主题与重复登记未拒绝 | 导航退化仍可能显示有效 | 非空、结构、描述、模块格式及主题内重复检查；跨主题共享模块仍合并去重 |
| 导航目标可指向仓库外 | 可能检查或建议执行非本树文件 | 限制模块名并拒绝解析到仓库外的符号链接；越界反例 |
| 任一主题损坏阻断其他主题 | 无关维护问题打断当前任务 | `--topic` 仅检查选中主题，`--check` 仍检查全表；双路径反例 |
| 生成命令依赖当前目录 | 换目录后可能使用错误解释器或找不到测试 | 使用当前工作树绝对路径并进行 shell 参数引用；空格路径测试及仓库外进程验证 |
| 默认重跑可能让首败被最终绿掩盖 | 日常交接漏记不稳定结果 | 导航命令显式关闭失败重跑；完整运行器默认行为不变，文档保留首败/flaky 规则 |
| 命令生成函数接受空模块列表 | 将来调用者可能意外生成全量发现命令 | 空列表直接拒绝；新增空命令反例，不悄悄扩大执行范围 |
| 缺少风险档位和共用结束判据 | 小任务过重，高风险任务验证不足 | 轻量/关联/扩大三档；逐项行为判据与未完成项规则；不是新增豁免 |
| 排查缺少收束，证据复用条件过粗 | 无边界搜索或把旧结论当当前事实 | 假设/反证/最小下一观测；补足依赖、权限、时效、测试输入和环境条件 |
| 仓库内输出目录与严格证据规则不一致 | 未跟踪证据可能进入构建输入或误提交 | 长任务优先仓库外证据；严格规则优先，不复制/手写关卡戳 |

导航反例位于 `tests/test_daily_workflow.py`；运行器行为与安全回归位于
`tests/test_coverage_runner_and_gate_failures.py`，复用 `tests/test_ui_dialog_guard.py`
与 `tests/test_coverage_release_tools.py` 的既有防线。反例只操作临时夹具，不修改正式安装。
