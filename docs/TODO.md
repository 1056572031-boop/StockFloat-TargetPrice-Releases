**本文件由人工维护。** 每周一至周五 09:00 的自动任务只读它、跟现场对账，**不写它**——
能自己改清单的闸门等于没有闸门。自动任务发现新增项或对账不上时，只在当天报告里提，

## 优先级怎么定（判据是规则，不是拍脑袋）

| 档 | 叫法 | 判据（任一成立即入这一档） |
| --- | --- | --- |
| P0 | 现在就管 | 程序现在用不了；你自己的数据有丢的风险；对外发出去的东西 404 或有法律/凭据问题；某道闸门当场红了 |
| P1 | 本周做 | 用户能看见的缺陷但还能用；下次发版前必须闭环（含源码没同步、诊断包申报缺失） |
| P2 | 排期做 | 账实不一致、观感、命名、清理、加固类 |
| 等你 | 需你拍板 | 机器不能替你决定：花钱、删线上资产、改策略、只能真机操作的事项 |

「已悬第几天」来自 `outputs/todo-runs/history.jsonl` 里同一 ID 连续出现的次数，不靠本文件里的日期估算。
同一「等你」项连续 3 个工作日无人回应，自动降为每周一列一次，不每天刷屏。
