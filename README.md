# Skyrocket

Mac 桌面上的股票行情小窗口。查看价格、涨跌幅和分时图，为股票设置目标价，到价时接收系统通知。它不连接券商账户，也不能下单。

当前版本：**v1.4.86 Beta**。更新日期：2026-10-15。

## 这版改了什么

完成主窗口职责拆分，保留入口与数据目录兼容；新增边界测试，完整回归和覆盖率门禁通过。

## 下载与安装

适用于 **Apple 芯片的 Mac**，要求 **macOS 13 或更高版本**；不提供 Intel、Windows 或 Linux 安装包。macOS 27 已在本机核验，macOS 26 和其他版本仍需实机验收，最低版本要求不代表全部版本均已测试。

1. 打开[官方下载页面](https://github.com/1056572031-boop/StockFloat-TargetPrice-Releases/releases/tag/%E7%89%88%E6%9C%AC%E6%9B%B4%E6%96%B0)，下载 `Skyrocket-V1.4.86.dmg`，不要下载页面底部 GitHub 自动生成的 Source code 作为安装包。
2. 双击打开 DMG，再双击磁盘里的「一键安装」。它会将程序安装到「应用程序」，旧版移到废纸篓保留，失败时显示原因。
3. 安装后打开 `Skyrocket`。若被系统拦截，先阅读[完整安装说明](docs/INSTALL.md)，核对来源和文件校验值。

发行页同时提供 `Skyrocket-1.4.86-SHA256SUMS.txt`，列出本版 DMG、应用 ZIP 和源码 ZIP 的 SHA-256。完整安装说明有校验命令；无法确认来源或校验不一致时不要运行。

**未签名、未公证：本项目没有 Apple Developer ID 开发者签名，也没有 Apple 公证。** 包内只有本地临时签名（ad-hoc），用于完整性检查，不能证明开发者身份或通过 Apple 安全审查。首次打开可能出现「身份不明的开发者」或「已损坏」提示；不要因此盲目放行，校验不一致或来源不明时应停止安装。

一键安装只处理本程序的下载隔离标记，不会关闭全系统 Gatekeeper，也不使用管理员命令。详细步骤、ZIP 安装方式和打不开的处理方法见[安装说明](docs/INSTALL.md)。

## 日常怎么用

- 在窗口的搜索入口输入股票名称或代码，选中后查看行情。
- 点击铃铛设置目标价；提醒需要 macOS 通知权限，也需要行情源正常和程序持续运行。
- 拖动窗口调整位置，点击收展；右键菜单里可以检查更新、导出诊断包和退出。
- 「自动隐藏窗口」默认关闭。主动开启并允许摄像头后，检测到附近第二张脸会把窗口收起；它不识别身份，也不能保证阻止他人看到屏幕。
- 窗口标注数据滞后或暂缺时，不应把显示的旧价格当成当前价格。集合竞价显示行情源现价，不承诺实时虚拟撮合价。

## 隐私说明

- 自选股票、目标价、窗口位置和缓存保存在本机的 `~/Library/Application Support/StockFloatTargetPrice/`。这个旧目录名为了保留升级前的数据而继续使用。
- 不收集券商账户、密码或持仓，不自动上传配置、日志或诊断包，没有内置使用行为遥测。
- **会发生网络请求**：查询行情时向腾讯、新浪、东方财富发送所查股票代码或搜索词；检查、下载更新时访问 GitHub 及其下载服务。这些服务会接收到 IP 地址和必要请求信息，并适用各自的隐私规则。这不等于查询完全匿名。
- 自动隐藏功能只在本机使用摄像头和 Apple Vision 统计人脸；正常运行不保存或上传画面。摄像头权限可在系统设置中撤销，拒绝不影响行情功能。
- 诊断包只在你主动导出时生成到桌面，不会自动发送。它可能包含股票代码、运行状态、系统版本、错误日志和经过脱敏的配置或崩溃片段；程序会遮盖已知凭据和用户路径，但不能保证所有第三方错误文本都无个人信息。**发送前请自行检查，不要直接贴到公开 Issue。**
- 删除应用不会自动删除上述数据目录；卸载后可自行决定保留还是删除。

## 从源码运行

开发环境需要 Python 3.14.7，所有依赖在工程自己的 `.venv` 中安装，不使用系统 Python 跑回归。

```sh
uv venv .venv --python 3.14.7
uv pip install --python .venv/bin/python --require-hashes -r requirements.lock
.venv/bin/python stock_float_window.py
QT_QPA_PLATFORM=offscreen ./run_tests.sh
```

独立构建和参与修改的注意事项见 [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md)。
